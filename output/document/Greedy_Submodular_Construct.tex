\begin{isamarkuptext}%
This theory sets up the greedy construction for monotone submodular
  maximization under a cardinality constraint. We fix a finite ground set
  \isa{V}, a budget \isa{k}, and a non-negative monotone submodular function
  \isa{f} over subsets of \isa{V}. The greedy sequence starts from the empty set
  and repeatedly adds an element with the largest marginal gain
  (ties broken arbitrarily).%
\end{isamarkuptext}\isamarkuptrue%
%
\begin{isamarkuptext}%
Locale \isa{Greedy{\isacharunderscore}{\kern0pt}Setup} encapsulates this standard setting. All subsequent
  definitions and lemmas are expressed relative to a fixed ground set \isa{V},
  budget \isa{k}, and set function \isa{f} satisfying the usual assumptions
  (finiteness, non-negativity, monotonicity, and submodularity).%
\end{isamarkuptext}\isamarkuptrue%
